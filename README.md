# Pikmin-Friends# 
🍄 皮友們集合囉！ (Pikmin Bloom Friends Tracker)

一個專為《Pikmin Bloom》玩家設計的輕量化 Web App，幫助你輕鬆記錄與管理好友的打菇戰績與明信片互動！

---

## ✨ 主要功能

* **🍄 蘑菇戰績記錄**：分類記錄 15 種蘑菇（一般、元素、活動限定）的打菇次數與歷史統計。
* **✉️ 明信片互動追蹤**：記錄與皮友互相發送明信片的次數。
* **📊 智慧排序與統計**：自動依據總互動次數、打菇或明信片次數排序，最熱絡的好友一目瞭然。
* **🏷️ 好友偏好標籤**：自訂好友偏好的蘑菇類型，揪團打菇更方便。
* **📱 支援手機 App 模式**：可新增至手機主畫面（PWA 體驗），隨開即用。
* **💾 本地資料儲存**：資料全數儲存於瀏覽器（LocalStorage），隱私無虞不外洩。
